# Client-Side Crystals 1.21.11 🐞💎

A purely visual **Fabric mod** that makes End Crystals appear instantly when placed.  
Client-side only, works on all servers, 100% harmless fun.  

---

## Requirements
- **Fabric Launcher** installed for Minecraft **1.21.11**  
- **Java** installed on PC  
- **Minecraft 1.21.11**  
- **Fabric API 1.21.11**  

---

## Installation
1. Download the ZIP file and extract the JAR.  
2. Copy the JAR file.  
3. Paste it into your Minecraft `mods` folder.  
   - Usually: `%appdata%/.minecraft/mods` on Windows  
4. Launch Minecraft with the Fabric profile.  
5. Place End Crystals and enjoy instant, zero-ping visuals! 💎

---

### Notes
- **Client-side only:** Does not give advantages in combat.  
- **Safe on all servers:** Just a visual mod.
